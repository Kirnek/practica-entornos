# practica-entornos

Aplicación Angular para la práctica de gestión de entornos con Git, GitHub y Vercel.

Ramas:

- main: producción (entorno verde).
- qa-pending: pruebas técnicas QA (entorno naranja).
- uat-pending: aceptación de usuario UAT (entorno azul).

Comandos:

- npm install
- npm start
- npm run build
